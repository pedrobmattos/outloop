# Outloop — Plano de Lançamento

**Outloop** é um estúdio de tecnologia que vende **automação de processos, sites profissionais e sistemas sob medida** para PMEs, começando por **Ribeirão Preto - SP e região**.

Este repositório contém o plano completo de lançamento: do plano de negócio à formalização, passando por precificação, landing page, tráfego pago, criativos e processo de vendas.

## Ângulos da marca

- **"Automatize sua empresa"**
- **"Pare com tarefas repetitivas"**
- **"Tenha o site e o sistema dos seus sonhos"**

## Funil

Anúncio (Meta CTWA + Google Search) → Landing page ou WhatsApp direto → Qualificação no WhatsApp → **Diagnóstico gratuito de automação (30 min)** → Proposta em até 48h → Fechamento.

## Regras de consistência

- **Preço**: a tabela do doc 02 é a fonte de verdade. Qualquer preço citado em outro doc (landing, scripts, anúncios) deve bater com ela.
- **Prazo de proposta**: até **48h** após o diagnóstico, em todos os materiais.
- **Fidelidade**: mensalidade de automação tem ciclo mínimo de **3 meses**; depois, cancelamento com aviso de 30 dias.
- **Pipeline do CRM**: Lead novo → Qualificado → Diagnóstico agendado → Diagnóstico feito → Proposta enviada → Fechado / Perdido.
- **Números de mercado**: benchmarks (CPL, conversões) são estimativas a validar com dados próprios nas primeiras 4–8 semanas.
